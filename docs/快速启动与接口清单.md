# 快速启动与接口清单

## 一、环境要求

| 组件 | 版本 | 说明 |
|---|---|---|
| JDK | 21 | 后端运行 |
| Maven | 3.9+ | 构建 |
| MySQL | 8.0 | 执行 `docs/sql/001`–`029`（按序号，连接加 `--default-character-set=utf8mb4`） |
| Redis | 7.x | 登录黑名单、限流 |
| Node.js | 20+ | Web/H5 前端 |
| Docker | 可选 | 跑容器测试需要 |

> 远程 MySQL/Redis 需在云安全组放行本机 IP。可用阿里云 CLI 临时放行：`aliyun ecs AuthorizeSecurityGroup --RegionId cn-shenzhen --SecurityGroupId sg-xxx --IpProtocol tcp --PortRange 3306/3306 --SourceCidrIp <本机IP>/32`，测完用 `RevokeSecurityGroup` 收回。

## 二、后端启动

```bash
# 1. 初始化数据库（按顺序执行 docs/sql 下 001–019）
mysql -h <host> -u root -p --default-character-set=utf8mb4 visitor_manage < docs/sql/001-integration.sql
# ... 依次到 019-access-sync.sql

# 2. 环境变量
DB_HOST=127.0.0.1
DB_PORT=3306
DB_NAME=visitor_manage
DB_USERNAME=root
DB_PASSWORD=******
REDIS_HOST=127.0.0.1
REDIS_PORT=6379
REDIS_PASSWORD=******
JWT_SECRET=<至少 32 位随机串>
INTEGRATION_MASTER_KEY=<32 字节 Base64>

# 3. 启动（默认 8080，接口前缀 /api）
mvn spring-boot:run
# 或
java -jar backend/target/visitor-backend-1.0.0-SNAPSHOT.jar
```

健康检查：`GET /api/health`，返回 database/redis 状态。

## 三、前端启动

```bash
cd frontend-web && npm install && npm run dev   # http://localhost:5173
cd frontend-h5  && npm install && npm run dev   # http://localhost:5174
```

两端 dev server 均把 `/api` 代理到 `http://localhost:8080`。

## 四、测试

```bash
# 后端：单元 + 集成 + 覆盖率门禁（行 ≥90%、分支 ≥65%）
cd backend && mvn verify

# 容器测试（真实 MySQL/Redis，需 Docker；2C2G 机器用受限参数见 backend/README）
mvn -Dtest=ContainerizedIntegrationTest test

# 前端 E2E（需先启动后端）
cd frontend-web && npm run test:e2e
cd frontend-h5  && npm run test:e2e
```

E2E 会自行创建测试账号与人员，可重复执行。

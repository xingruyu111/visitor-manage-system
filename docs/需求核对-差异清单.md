## 三、建议补做顺序（不依赖学校接口）

1. 通行方式字段（步行/电动自行车/机动车）+ 申请页选择 + 校验；
2. 黑名单申请前预检接口 + H5 醒目提示；
3. 校友快速预约自动审批；
4. 附属学生班主任工号字段与按工号解析；
5. 审批历史查询 + Web/H5 紧急审批入口 + 审批意见展示；
6. IP 黑名单维护接口/页面；
7. 系统参数配置页（过期策略、最长在校、重复识别、非常规时段）；
8. Web 同步任务页（手动触发/记录）；
9. 大屏（可选，按需定制）。
